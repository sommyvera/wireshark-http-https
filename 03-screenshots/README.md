## Screenshot Rule

Before publishing screenshots, remove or blur:

- Real usernames
- Passwords
- Session tokens
- Cookies
- Personal information
- Private IP addresses if they reveal sensitive infrastructure

Screenshots should demonstrate your technical work without exposing secrets.
